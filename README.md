# 🎮 MatchIt!

**MatchIt!** is a casual Android mobile game developed with **Unity** that focuses on testing color perception, attention, and reaction speed.

The player is presented with one main reference color and four selectable color options.
The objective is to correctly match the reference color as many times as possible while the difficulty gradually increases.

---

## 📱 Platform
- Android

---

## 🛠️ Technologies
- Unity
- C#
- Android SDK
- Firebase Authentication
- Firebase Realtime Database
- Unity Ads

---

## 🎯 Gameplay Overview
- One main reference color is shown to the player
- Four color options are available to choose from
- Correct matches increase the score
- Difficulty increases by reducing color contrast
- Designed to be simple to learn but challenging to master

---

## 🔐 Authentication & Data Storage
The game includes a **user login system** implemented using **Firebase Authentication**.
Player progress and score data are stored using **Firebase Realtime Database**, allowing persistent data storage across sessions.

---

## 📢 Monetization
The project integrates **Unity Ads** to display in-game advertisements as a basic monetization feature.
